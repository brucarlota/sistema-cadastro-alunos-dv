# Sistema de Cadastro de Alunos

Desafio em Squad – Sistema de cadastro de alunos com CSharp.

Aplicação de console desenvolvida em **C#** para gerenciar o cadastro e a consulta de alunos.

# Conceitos e Recursos Utilizados

- Lógica de programação;
- Variáveis e coleções;
- Conversão de tipos;
- Operadores e expressões;
- Estruturas condicionais e de repetição;
- Funções.

## Funcionalidades

- Cadastrar novos alunos;
- Utilizar alunos previamente cadastrados;
- Listar todos os alunos registrados;
- Buscar aluno pelo nome;
- Exibir somente os alunos aprovados;
- Calcular e apresentar a média geral da turma;
- Encerrar o sistema pelo menu.

## Fluxo de navegação

### Menu inicial

Ao iniciar o programa, o usuário pode escolher entre:

1. Cadastrar novos alunos;
2. Acessar os alunos já cadastrados;
3. Encerrar o sistema.

### Menu de consultas

Após acessar os alunos cadastrados, as opções disponíveis são:

1. Listar alunos cadastrados;
2. Buscar aluno por nome;
3. Exibir alunos aprovados;
4. Exibir a média geral da turma;
5. Encerrar o sistema.
